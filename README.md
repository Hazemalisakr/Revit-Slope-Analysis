Revit Slope Analysis Add-in
A professional Revit Add-in designed to analyze and calculate floor slopes with precision. This tool features a custom WPF interface optimized for 4K displays and provides real-time feedback during the selection process.

🚀 Key Features
Accurate Analysis: Calculates slopes for selected floors based on internal Revit geometry.
4K Optimized UI: Clean, modern WPF interface that scales perfectly on high-resolution monitors.
Real-Time Guidance: Integrated status bar and user prompts to prevent Revit freezing during floor selection.
Multi-Version Support: Compatible with Revit 2020 through 2026.

🛠️ Built With
C# / .NET 4.8
Revit API
WPF (Windows Presentation Foundation) for the UI
Inno Setup for the professional installer
